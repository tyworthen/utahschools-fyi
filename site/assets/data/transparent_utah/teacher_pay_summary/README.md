# Transparent Utah — classroom teacher pay, district summary

Generated by `scripts/summarize_teacher_pay.py` from the State Auditor's Teacher Pay dashboard
(https://transparent.utah.gov/teacher-pay/, "Teacher Data" table, FY2014-FY2025, retrieved 2026-10-31).

The downloads list individual teachers by name and CACTUS ID, so they are kept outside the published
site (`private_data/`, excluded from git) and never published. This file contains only district-level
statistics: number of teachers and the 25th/50th/75th percentiles and mean of instructional wages,
total wages, and total compensation. Statistics for groups of fewer than 10 teachers are left blank.

Coverage: only teachers matched to at least one course in USBE's CACTUS database; the match rate
varies by district and year, so `teachers` is not a full headcount.

A teacher who teaches at more than one school appears once per school in the downloads, with the
same pay on each row; `teachers` counts each CACTUS ID once per district and year.
