# BLS Consumer Price Index — raw downloads

CPI-U, U.S. city average, all items, not seasonally adjusted (series CUUR0000SA0), monthly,
January 2011 to September 2026, from the BLS Public Data API (v1), retrieved 2026-10-31.

October 2025 has no value ("-"): BLS did not publish October 2025 CPI data because of the
2025 federal government shutdown. The fiscal-year average for FY2026 (July 2025-June 2026)
therefore uses the 11 available months.

Normalized output: `../normalized/inflation.csv` (fiscal-year averages and adjustment factors).
