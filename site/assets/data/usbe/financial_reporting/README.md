# USBE Financial Reporting — raw downloads

All Excel files linked from https://schools.utah.gov/financialoperations/reporting,
retrieved 2026-10-31. Folder structure mirrors USBE's URL paths (several files share
a name across years). Do not edit these files; they are the preserved originals.
`manifest.csv` records each file's source URL, size, SHA-256, sheet names, and
whether it mentions Tooele.

## chartofaccounts/
FY2025, FY2026, FY2027 Utah chart of accounts: fund, revenue, function, object,
program, and balance sheet codes. Use as the code dictionary for the reports below.

## reports/annualfinancialreport/ — AFR summaries (FY2023, FY2024, FY2025)
One workbook each for Revenue, Expenditure, Balance Sheet, and Other Sources /
Other Financing. One sheet per fund (10 General, 20–23 special revenue,
26, 31–32 capital, 40, 49/51 debt service, 50/60 proprietary) plus fund totals.
Rows are LEAs (e.g. `030 Tooele District`); columns are account codes.

## reports/annualfinancialreport/*/…annualprogramreport…/ and reports/annualprogramreport/
APR summaries (FY2023–FY2025), Schedules A (general education), B (special
education), C (CTE), D (special populations), H (restricted state/federal),
I (one-time), J (non-instructional: food service, debt service, foundation, etc.),
L (ESEA / Title programs). Revenue and spending by program and LEA.

Not downloaded: PDFs on the same page (accounting handbook, indirect cost
schedules, chart-of-accounts PDFs) and any older years on the sub-pages
afrrevenue.php, afrexpenditures.php, afrbalancesheet.php.
